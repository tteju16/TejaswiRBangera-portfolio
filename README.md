# Tejaswi R Bangera — Portfolio

A responsive single-page software developer portfolio built with plain HTML, CSS and JavaScript.

## Included
- Responsive dark/light portfolio UI
- User-provided profile photo
- About, skills, experience, projects, education and contact sections
- Project filtering
- Scroll reveal animations
- Mobile navigation
- GitHub repository links
- Resume project highlights

## Run locally
Open `index.html` in a browser.

## Deploy
This is a static site and can be deployed to GitHub Pages, Vercel or Netlify.
